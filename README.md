## 🧪 Projects

### 🔥 Real-Time Fire & Smoke Detection

Developed a real-time fire and smoke detection system using **YOLO + PyTorch**, with a custom-labeled dataset and Roboflow-based dataset pipeline.

> `Object Detection` `YOLO` `PyTorch` `Computer Vision` `Real-Time AI`

### 🚒 Autonomous Firefighting Robotic Vehicle

Contributed substantially to an embedded robotic system capable of **detecting fire, navigating toward the detected source, and activating an automated extinguishing mechanism**.

> `ATmega328P` `Flame Sensors` `Motor Control` `Embedded C` `Robotics`

### ♿ Gesture-Controlled Wheelchair

Designed and developed a prototype using an **ADXL335 accelerometer** to translate human hand movements into real-time wheelchair navigation commands through an embedded sensing and motor-control pipeline.

> `Arduino Nano` `Accelerometer` `Embedded Systems` `Human-Robot Interaction`

### 📡 IoT-Based Real-Time Monitoring

Built ESP32-based systems for real-time sensor acquisition, MQTT communication, web-based monitoring, and event-driven alerts.

> `ESP32` `MQTT` `IoT` `Sensors` `Real-Time Systems`
